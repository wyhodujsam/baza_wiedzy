# ogrod-sad — plan mini sadu przy domu

- **Katalog:** `~/apps/ogrod-sad`
- **Repo:** github.com/wyhodujsam/ogrod-sad (private)
- **Stack:** HTML + SVG + vanilla JS, bez zależności; dane w `plan.js` (metry)
- **Uruchomienie:** otworzyć `index.html`; z telefonu `python3 -m http.server 8090`

Interaktywny schemat działki 20-33/44 (ul. Brzeziny): dom, kostka, płot, media z mapy
inwentaryzacji (wodociąg, zbiornik LPG, kabel, kanalizacja), rośliny istniejące i
propozycje nasadzeń w pasie przy północnym płocie.

Edytor: tryby Zaznacz / Dodaj / Miarka, przeciąganie, panel właściwości, warstwy,
eksport `plan.js` (szkic trzymany w localStorage). Nowy typ elementu = wpis w `TYPY`.

Wymiary są **szacunkiem z fotografii mapy** — lista pomiarów do weryfikacji w README.
