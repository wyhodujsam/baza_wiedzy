A. Obraz do sceny (Chełmno, kadr 3)

  1. telefon

    „Wygeneruj jeszcze obrazy do tej sceny." Prompt idzie z mobilnego UI przez Tailscale do claude-remote.

  2. claude-remote

    Uruchamia claude w katalogu domowym i otwiera strumień SSE z powrotem na telefon.

  3. Claude Code · Fable

    Czyta tekst sceny i kanoniczne opisy lokacji, wybiera kadry, pisze prompty do pliku w repo grafiki/PROMPTY-gpt-image.md (wersje v1/v2/v3).

    źródło spójności: research/2026-06-14-opisy-lokacji-do-promptow.md
  4. Claude Code

    Zleca w tle: codex exec -m gpt-6-astra … -o wynik.md "Użyj $imagegen, przeczytaj plik promptów, zapisz PNG do grafiki/". Skrypt kończy się exit 0, Claude czeka na powiadomienie.

    przed startem: codex-trace → LIMITY 5h / tydzień
  5. Codex CLI · Astra

    W sandboxie bwrap czyta plik promptów, wywołuje skill $imagegen, przenosi wynik z ~/.codex/generated_images do repo.

  6. OpenAI · gpt-image-2

    Generuje obraz. Moderacja na wyjściu: kadry z rannymi i pogrzeb odrzucone („violence"), przechodzi statyczny kadr bez kontaktu.

    koszt: ~3–4% okna 5 h na obraz, wspólna pula z ChatGPT
  7. Codex CLI

    Odrzucenie → Claude łagodzi prompt (v2, v3) i zleca ponownie. Sukces → ścieżka PNG w komunikacie końcowym.

  8. Claude Code · Fable

    Ogląda PNG (Read), ocenia zgodność z kanonem lokacji, dopisuje KREDYTY.md, buduje stronę porównawczą i publikuje artefakt HTML.

  9. git · GitHub

    Commit na branch tekst/12-chelmno, push zweryfikowany przez SHA remote'a, obrazy widoczne w PR #44.

  10. telefon

    Link do artefaktu w odpowiedzi SSE. Ocena kadrów i ewentualna poprawka („woda nie zamarznięta") → od kroku 4 w trybie edycji istniejącego obrazu.

B. Scena z Astrą jako Pisarzem

  1. telefon

    „Wyślij do Astry polecenie napisania sceny jatki, brief jak dla naszego pisarza, redakcja i korekta w Fable."

  2. Claude Code · Fable

    Etap 0: brief (funkcja, kanon, twarde ograniczenia z gotowej prozy), tło z planem karczmy, zlecenie z listą plików do przeczytania w kolejności i notą „mniej sarkazmu".

  3. Claude Code

    codex exec … -c model_reasoning_effort="high" w tle przez nohup. Zlecenie jest samowystarczalne: Codex nie widzi sesji Claude.

  4. Codex CLI · Astra

    Czyta ~20 plików kanonu, pisze draft 5,5 tys. słów do 20-draft-astra.md, raportuje sprzeczności w materiałach.

    18 min · 2,9 M tokenów in · ~55% okna 5 h
  5. Subagent · Redaktor (Fable)

    Trzy osie (kanon, rejestr, dramaturgia) + przebieg powtórzeń. Raport 55 zmian i 10 punktów do decyzji autora.

  6. Subagent · Korektor (Fable)

    Tylko język. 9 pewnych poprawek naniesionych, 27 wątpliwych zostawionych autorowi.

  7. Claude Code

    Wersja końcowa do tekst/12-chelmno.md, renumeracja rozdziałów, rejestry (SCENY, WATKI, obietnice), strona diff draft ↔ finał.

  8. git · GitHub

    Branch tekst/12-chelmno, PR #44 otwarty na uwagi. Skill /1413-audyt przed merge.

  9. telefon

    Czytanie porównania w artefakcie, decyzje autora (np. małpa → niedźwiednik) wracają jako kolejne prompty.

Codex dostaje samowystarczalne zlecenia w plikach, gdy potrzebny jest drugi model, obraz albo niezależna weryfikacja.
